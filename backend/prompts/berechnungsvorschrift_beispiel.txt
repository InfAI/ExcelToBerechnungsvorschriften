# Beispiele: Excel-Formel → Berechnungsvorschrift (JSON)

Format: BEISPIEL-EINGABE (Zelleneingabe) gefolgt von GEWÜNSCHTES JSON-OUTPUT.
Im Output nur die Felder name, formel, variablen, metadaten. Kein referenz_berechnungsvorschrift_id; jede Variable mit ist_primitive: true.
Variablennamen im formel-String müssen exakt mit variablen[].name übereinstimmen.

---

BEISPIEL 1 – Einfache Formel, eine Variable

BEISPIEL-EINGABE:
Tabellenidentifikator: Tabelle1
Tabellenblatt: Sheet1
Zellenidentifikator: A1
Beschreibung: Monatliches Nettogehalt berechnen
Formel: =B1/12

GEWÜNSCHTES JSON-OUTPUT:
{
  "name": "monatliches Nettogehalt",
  "formel": "Jahresnettogehalt / 12",
  "variablen": [
    {
      "name": "Jahresnettogehalt",
      "ist_primitive": true
    }
  ],
  "metadaten": {
    "kategorie": "Gehalt",
    "symbol": "MNG",
    "datentyp": "decimal",
    "einheit": "EUR"
  }
}

Erklärung: B1 wird aus der Beschreibung ("Nettogehalt") als "Jahresnettogehalt" interpretiert. Der Name "Jahresnettogehalt" erscheint exakt so in formel.

BEISPIEL 4 – IFERROR: nur Wert-Teil übernehmen

Fehlerbehandlungs-Funktionen (IFERROR, IFNA) nicht in den Pseudocode übernehmen. Nur den ersten Parameter (den eigentlichen Ausdruck) in Pseudocode umwandeln; Ersatzwert und Fehlerbehandlung weglassen.

BEISPIEL-EINGABE:
Tabellenidentifikator: Tabelle1
Tabellenblatt: Sheet1
Zellenidentifikator: E5
Beschreibung: Umsatz pro Einheit (ohne Fehleranzeige)
Formel: =IFERROR(A1/B1;"-")

GEWÜNSCHTES JSON-OUTPUT:
{
  "name": "Umsatz pro Einheit",
  "formel": "Umsatz / Menge",
  "variablen": [
    {
      "name": "Umsatz",
      "ist_primitive": true
    },
    {
      "name": "Menge",
      "ist_primitive": true
    }
  ],
  "metadaten": {
    "kategorie": "Umsatz",
    "symbol": "UPE",
    "datentyp": "decimal",
    "einheit": "EUR/Stk"
  }
}

Erklärung: Nur A1/B1 wird umgewandelt → "Umsatz / Menge". Der Ersatzwert "-" und die Fehlerbehandlung von IFERROR erscheinen nicht im Pseudocode.

BEISPIEL 6 – IFERROR + SUMIFS/COUNTIFS, Tabellenbezüge, eine Zellvariable (A9)

Formel nutzt IFERROR (nur Wert-Teil übernehmen), SUMIFS/COUNTIFS (bedingte Summe/Anzahl) und Tabellenbezüge (MAJahr1[Spalte]).
Nur A9 ist eine Zellreferenz → genau eine Variable. Tabellenbezüge erzeugen keine Variablen.

BEISPIEL-EINGABE:
Tabellenidentifikator: MAJahr1
Tabellenblatt: Sheet1
Zellenidentifikator: B10
Beschreibung: Durchschnittliche Arbeitsstunden pro Jahr nach Ausbildungsstand
Formel: =IFERROR(SUMIFS(MAJahr1[Arbeitsstunden/ Jahr],MAJahr1[Ausbildungsstand],A9)/COUNTIFS(MAJahr1[Ausbildungsstand],A9)," ")

GEWÜNSCHTES JSON-OUTPUT:
{
  "name": "Durchschnittliche Arbeitsstunden pro Jahr nach Ausbildungsstand",
  "formel": "Summe Arbeitsstunden pro Jahr (gefiltert nach Ausbildungsstand) / Anzahl Einträge (gefiltert nach Ausbildungsstand)",
  "variablen": [
    {
      "name": "Ausbildungsstand",
      "ist_primitive": true
    }
  ],
  "metadaten": {
    "kategorie": "Personal",
    "symbol": "DAPJ",
    "datentyp": "decimal",
    "einheit": "h"
  }
}

Erklärung: IFERROR wird weggelassen (nur der erste Parameter wird umgewandelt). A9 kommt zweimal vor (in SUMIFS und COUNTIFS) → trotzdem nur eine Variable "Ausbildungsstand". MAJahr1[Arbeitsstunden/ Jahr] und MAJahr1[Ausbildungsstand] sind Tabellenbezüge, keine Zellreferenzen → keine zusätzlichen Variablen. Der Variablenname "Ausbildungsstand" erscheint exakt so in formel.
