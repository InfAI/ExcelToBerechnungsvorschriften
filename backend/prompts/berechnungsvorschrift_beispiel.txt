# Beispiele: Excel-Formel → Berechnungsvorschrift (JSON)

Format: EINGABE (Tabellenidentifikator, Tabellenblatt, Zellenidentifikator, Beschreibung, Formel) → JSON.
Regeln: name="N/A"; referenz_berechnungsvorschrift_id nie setzen. Jede Wertquelle = Variable; formel nur mit exakten Variablennamen. Zellreferenz → zellenidentifikator (ohne $); fremdes Blatt → tabellenblatt_referenz. metadaten: alle vier Felder (kategorie, symbol, datentyp, einheit) aus Kontext ableiten.

---

BEISPIEL 1 – Einfach, eine Variable

EINGABE:
Tabellenidentifikator: Tabelle1
Tabellenblatt: Sheet1
Zellenidentifikator: A1
Beschreibung: Monatliches Nettogehalt berechnen
Formel: =B1/12

JSON:
{
  "name": "N/A",
  "formel": "Jahresnettogehalt / 12",
  "variablen": [{"name": "Jahresnettogehalt", "ist_primitive": true, "zellenidentifikator": "B1"}],
  "metadaten": {"kategorie": "Gehalt", "symbol": "MNG", "datentyp": "decimal", "einheit": "EUR"}
}

Erklärung: B1 → Variable mit zellenidentifikator "B1". Matching findet BVs, deren quelle.zellenidentifikator=B1 im gleichen Blatt.

BEISPIEL 2 – AVERAGE, mehrere Zellen

EINGABE:
Tabellenidentifikator: Tabelle1
Tabellenblatt: Sheet1
Zellenidentifikator: C10
Beschreibung: Durchschnitt der Quartalsumsätze
Formel: =AVERAGE(B1,B2,B3,B4)

JSON:
{
  "name": "N/A",
  "formel": "(Quartalsumsatz_1 + Quartalsumsatz_2 + Quartalsumsatz_3 + Quartalsumsatz_4) / 4",
  "variablen": [
    {"name": "Quartalsumsatz_1", "ist_primitive": true, "zellenidentifikator": "B1"},
    {"name": "Quartalsumsatz_2", "ist_primitive": true, "zellenidentifikator": "B2"},
    {"name": "Quartalsumsatz_3", "ist_primitive": true, "zellenidentifikator": "B3"},
    {"name": "Quartalsumsatz_4", "ist_primitive": true, "zellenidentifikator": "B4"}
  ],
  "metadaten": {"kategorie": "Umsatz", "symbol": "DQ", "datentyp": "decimal", "einheit": "EUR"}
}

Erklärung: AVERAGE → explizite Pseudocode; jede Zelle eigene Variable. SUMME(B1:B12) analog → Monatsumsatz_1…12.

BEISPIEL 3 – IFERROR (nur Wert-Teil)

EINGABE:
Tabellenidentifikator: Tabelle1
Tabellenblatt: Sheet1
Zellenidentifikator: E5
Beschreibung: Umsatz pro Einheit (ohne Fehleranzeige)
Formel: =IFERROR(A1/B1;"-")

JSON:
{
  "name": "N/A",
  "formel": "Umsatz / Menge",
  "variablen": [
    {"name": "Umsatz", "ist_primitive": true, "zellenidentifikator": "A1"},
    {"name": "Menge", "ist_primitive": true, "zellenidentifikator": "B1"}
  ],
  "metadaten": {"kategorie": "Umsatz", "symbol": "UPE", "datentyp": "decimal", "einheit": "EUR/Stk"}
}

Erklärung: IFERROR weglassen – nur A1/B1 umwandeln. Ersatzwert "-" und Fehlerbehandlung erscheinen nicht.

BEISPIEL 5 – SUMIFS/COUNTIFS, Tabellenspalte

EINGABE:
Tabellenidentifikator: MAJahr1
Tabellenblatt: Sheet1
Zellenidentifikator: B10
Beschreibung: Durchschnittliche Arbeitsstunden pro Jahr nach Ausbildungsstand
Formel: =IFERROR(SUMIFS(MAJahr1[Arbeitsstunden/Jahr],MAJahr1[Ausbildungsstand],A9)/COUNTIFS(MAJahr1[Ausbildungsstand],A9)," ")

JSON:
{
  "name": "N/A",
  "formel": "Summe(Arbeitsstunden_pro_Jahr, gefiltert nach Ausbildungsstand) / Anzahl(gefiltert nach Ausbildungsstand)",
  "variablen": [
    {"name": "Ausbildungsstand", "ist_primitive": true, "zellenidentifikator": "A9"},
    {"name": "Arbeitsstunden_pro_Jahr", "ist_primitive": true}
  ],
  "metadaten": {"kategorie": "Personal", "symbol": "DAPJ", "datentyp": "decimal", "einheit": "h"}
}

Erklärung: A9 (Zellreferenz) → zellenidentifikator "A9". Tabellenspalte MAJahr1[Arbeitsstunden/Jahr] (Summenbereich) → Variable ohne zellenidentifikator. IFERROR weglassen.

BEISPIEL 6 – INDEX/MATCH

EINGABE:
Tabellenidentifikator: Lohn
Tabellenblatt: Sheet1
Zellenidentifikator: J10
Beschreibung: Lohnwert aus Tabelle Lohn für Ausbildungsstand und Spaltenkopf
Formel: =INDEX(Lohn[],MATCH(H9,Lohn[Ausbildungsstand],0),MATCH(I4,Lohn[#headers]))

JSON:
{
  "name": "N/A",
  "formel": "Wert aus Lohn_Tabelle an Zeile(Ausbildungsstand) und Spalte(Spaltenkopf)",
  "variablen": [
    {"name": "Lohn_Tabelle", "ist_primitive": true},
    {"name": "Ausbildungsstand", "ist_primitive": true, "zellenidentifikator": "H9"},
    {"name": "Spaltenkopf", "ist_primitive": true, "zellenidentifikator": "I4"}
  ],
  "operation": "index_lookup",
  "metadaten": {"kategorie": "Personal", "symbol": "LWT", "datentyp": "decimal", "einheit": "EUR"}
}

Erklärung: operation="index_lookup" für 2D-Tabellenlookup. Variablenreihenfolge zwingend: (1) Tabelle, (2) Zeilenkriterium H9, (3) Spaltenkriterium I4. Auswertung: lookup(Tabelle, Zeilenkey, Spaltenkey). Lohn[Ausbildungsstand] und Lohn[#headers] sind Lookup-Bereiche, keine eigenen Variablen.

---

BEISPIEL 7 – Cross-Sheet

EINGABE:
Tabellenidentifikator: Tabelle1
Tabellenblatt: Übersicht
Zellenidentifikator: E10
Beschreibung: Lohnanteil als Prozentwert
Formel: =$'1. Lohn AW'.G19/100

JSON:
{
  "name": "N/A",
  "formel": "Lohnwert / 100",
  "variablen": [{"name": "Lohnwert", "ist_primitive": true, "zellenidentifikator": "G19", "tabellenblatt_referenz": "1. Lohn AW"}],
  "metadaten": {"kategorie": "Personal", "symbol": "LAP", "datentyp": "decimal", "einheit": "%"}
}

Erklärung: G19 liegt im Blatt "1. Lohn AW", die Formel in "Übersicht". tabellenblatt_referenz zwingend – ohne dies sucht Matching nur im Formel-Blatt und findet die BV für G19 nicht.

---

BEISPIEL 8 – SUM(COUNTIFS(...)) mit Cross-Sheet-Kriterien (2 Variablen)

EINGABE:
Tabellenidentifikator: Soziales
Tabellenblatt: 2. Arbeitszeit AW
Zellenidentifikator: B8
Beschreibung: Anzahl MA – Vollzeit festangestellt
Formel: =SUM(COUNTIFS(MAJahr1[Angestelltenverhältnis],'INTERN BEZÜGE'!$D$3,MAJahr1[Wie viele Monate des Jahres im Betrieb angestellt?],'INTERN BEZÜGE'!E5),COUNTIFS(MAJahr2[Angestelltenverhältnis],'INTERN BEZÜGE'!$D$3,MAJahr2[Wie viele Monate des Jahres im Betrieb angestellt?],'INTERN BEZÜGE'!E5),COUNTIFS(MAJahr3[Angestelltenverhältnis],'INTERN BEZÜGE'!$D$3,MAJahr3[Wie viele Monate des Jahres im Betrieb angestellt?],'INTERN BEZÜGE'!E5))

JSON:
{
  "name": "N/A",
  "formel": "Anzahl(MAJahr1, Angestelltenverhältnis=Kriterium_Angestelltenverhältnis, Monate_im_Betrieb=Kriterium_Monate) + Anzahl(MAJahr2, Angestelltenverhältnis=Kriterium_Angestelltenverhältnis, Monate_im_Betrieb=Kriterium_Monate) + Anzahl(MAJahr3, Angestelltenverhältnis=Kriterium_Angestelltenverhältnis, Monate_im_Betrieb=Kriterium_Monate)",
  "operation": "count_filter",
  "operation_parameter": {"tabellen": ["MAJahr1", "MAJahr2", "MAJahr3"], "aggregation": "summe"},
  "variablen": [
    {"name": "Kriterium_Angestelltenverhältnis", "ist_primitive": true, "zellenidentifikator": "D3", "tabellenblatt_referenz": "INTERN BEZÜGE", "quelle_typ": "zelle", "kriterienbereich": "Angestelltenverhältnis", "vergleichsoperator": "="},
    {"name": "Kriterium_Monate", "ist_primitive": true, "zellenidentifikator": "E5", "tabellenblatt_referenz": "INTERN BEZÜGE", "quelle_typ": "zelle", "kriterienbereich": "Wie viele Monate des Jahres im Betrieb angestellt?", "vergleichsoperator": "="}
  ],
  "metadaten": {"kategorie": "Personal", "symbol": "AMV", "datentyp": "integer", "einheit": "Stk"}
}

Erklärung: Nur Kriterienzellen D3, E5 (INTERN BEZÜGE) = Variablen. Tabellenspalten (MAJahr1[Angestelltenverhältnis], MAJahr1[Wie viele Monate...], ...) sind KEINE Variablen – sie dienen nur der Filterlogik. kriterienbereich = Spaltenname, auf den das Kriterium angewendet wird. operation: "count_filter" mit operation_parameter: tabellen, aggregation.
